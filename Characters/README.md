# キャラクター選択と画像取り込み（Windows版）

起動すると、モックを基にした日本語のキャラクター選択画面が開きます。
左に縦横比を保った画像プレビュー、右に名前・紹介文・表示切り替え、下にキャラ一覧と決定ボタンを配置しています。

## 使い方

1. キャラクターを選び、「表示・取り込み先」から画像の用途を選ぶ。
2. 「画像を取り込む」でPNG/JPEGを選ぶ。透過PNGにも対応。
3. 登録後は自動保存。別の画像を選べば差し替え。「この画像を解除」で登録だけ削除できる。
4. 抜刀剣士を選び、「このキャラクターで決定」→「対戦を開始」。既存の操作説明へ進む。
5. 対戦終了後、F2でキャラ選択に戻る。対戦中は使用不可。Escapeはゲーム終了。

| ID | キャラ | 対応 |
|---|---|---|
| 0001 | 抜刀剣士（仮） | 既存の戦闘処理で対戦可 |
| 0002 | ミア | 画像登録・紹介・プレビュー。専用戦闘処理が未実装のため対戦不可 |

ミアは別キャラクターです。既存の抜刀剣士の技をミアの技として流用していません。

| 画像の用途 | 保存名 | 使用箇所 |
|---|---|---|
| 納刀／立ち姿 | portrait.png | 選択画面 |
| 抜刀／別ポーズ | alternate.png | 選択画面 |
| 顔アイコン | icon.png | 選択画面と対戦中の両者HUD |
| 対戦用の静止画 | battle.png | 対戦キャラ表示。顔の向きは右向きを推奨。足元を下端に揃える |

対戦用の静止画は任意です。未登録なら従来の描画を使います。静止画の拡大縮小・左右反転はしますが、アニメーションは生成しません。攻撃や当たり判定は既存のものです。大きな余白を含む絵は余白も含めて縮小されます。画像のみで新しい技は追加されません。

## 保存先

`%LOCALAPPDATA%\Chozetumokosatugekiranzan\Characters\0001\`（ミアは `0002`）

原本は変更せず、アプリ用のPNGコピーを保存します。原本を移動・削除しても登録画像は残ります。ZIPを展開し直しても同じWindowsユーザーなら読み込みます。
1ファイル32MB以下、各辺4096px以下、1600万画素以下。対応外・破損画像・保存失敗はエラー表示し、既存の登録を保持します。登録解除は原本を消しません。
画像はユーザー側で登録します。この変更に生成済みのイラスト自体は同梱していません。

## 開発と検証

Windows Formsを使用するためターゲットを `net10.0-windows` に変更しました。SDKは既存の `global.json` に従います。

```powershell
dotnet restore
dotnet build -c Release
dotnet run -- --self-test
dotnet run
```

配布用（.NETランタイム同梱）：

```powershell
dotnet publish -c Release -r win-x64 --self-contained true -o publish
```

`publish` フォルダ全体を配布してください。

セルフテストには、PNG透過・JPEG・日本語パス・原本削除後の再読込・差し替え・キャラIDの分離・登録解除・破損/過大画像の拒否・失敗時の既存画像保持を含みます。

Windows実機での確認項目：
- 100% / 150% / 200%の画面倍率で、文字とボタンが見切れない。
- 縦長・横長・透過PNGを各枠に登録し、縦横比と透過を確認。
- ファイル選択をキャンセルしても登録画像が変わらない。
- 終了後に再起動して画像が残る。元画像を移動しても表示される。
- 破損画像を選んでも落ちず、前の画像が残る。
- ミアの画像登録後も、抜刀剣士の画像・技が変わらない。
- 抜刀剣士を決定して操作説明→対戦へ進む。決定入力で攻撃が発動しない。
- HUDアイコン、静止画の左右反転、透過表示、結果画面からF2で戻る動作を確認。

選択画面はWindows標準の日本語フォントを使用します。既存の日本語操作説明と後退・明示ガードの修正を維持しています。
